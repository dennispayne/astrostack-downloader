# Support

`wgfetch` is a small, volunteer-maintained project. There is no commercial support and no service
level agreement, but questions are welcome.

## Before asking

- Read the [README](README.md) for the CLI surface, exit codes and privacy behaviour.
- Read [`docs/REQUIREMENTS.md`](docs/REQUIREMENTS.md) — it is the authoritative specification and
  usually answers "is this a bug or is it intended?".
- Search [existing issues](https://github.com/dennispayne/astrostack-downloader/issues?q=is%3Aissue).

## Where to ask

| You want to | Go to |
| --- | --- |
| Ask a usage question or discuss an idea | [New issue](https://github.com/dennispayne/astrostack-downloader/issues/new/choose) — say up front that it is a question rather than a bug report |
| Report a bug or request a feature | [New issue](https://github.com/dennispayne/astrostack-downloader/issues/new/choose) |
| Report a security vulnerability | [`SECURITY.md`](SECURITY.md) — **never** a public issue |
| Contribute a change | [`CONTRIBUTING.md`](CONTRIBUTING.md) |

## Helping us help you

Include the exact command line, the `wgfetch --version` output, your operating system, and the
relevant log or `--json` output. **Redact API keys and tokens before pasting anything.**

Responses are best-effort and may take several days.
